    Data embedded from the NAEB feature-service exports (Importers / Aggregators_Exporters / Stations / Purchases / Sourcing / Deliveries) with illustrative farmer and farm (plot) records added for the prototype. Each record links to the others purely through IDs, so when this page is hosted on the NAEB portal the arrays can be swapped for live queryFeatures() calls unchanged. Farm boundaries on the map are schematic. Selection state is kept in the URL hash, so a traced chain can be shared as a link.
